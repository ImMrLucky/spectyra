Session analytics

What this page is: session rollups from redacted session summaries synced when a client enables cloud sync, plus aggregated metrics from the in-app SDK when your server sends POST /v1/telemetry/run (default-on cloud telemetry when a Spectyra API key is configured). Nothing here includes raw prompts.

Not the same as “Usage” in the sidebar: Workspace usage is your plan, limits, and billing snapshot. Per-project drill-downs also live under Projects.

When does session sync appear? Only when you enable it in a client that supports it — for example Local Companion’s sync-to-cloud setting, or the Spectyra desktop app posting session summaries while signed in. If you never turned that on, session cards below may show zeros while SDK telemetry still has data.

In-app SDK: with SPECTYRA_API_KEY (or spectyraCloudApiKey), the SDK defaults to sending aggregated savings and token metrics each complete(). Set telemetry: { mode: 'local' } to turn that off.
